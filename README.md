# 📊 Adventure Works Sales Performance Dashboard | Power BI Project

## 📖 Project Overview

This Power BI project was completed as part of my **Level 3 Data Technician Skills Bootcamp** and demonstrates my ability to transform raw business data into meaningful insights through interactive dashboards and visualisations.

Using Adventure Works sales data, I designed a dynamic dashboard that enables stakeholders to monitor sales performance, compare results against targets, evaluate profitability, and analyse trends across regions, countries, and product categories.

> 📊 In a world full of data, I'm learning how to find the signal in the noise.

---

## 🎯 Project Objectives

- Analyse company sales performance across multiple financial years
- Compare actual sales against business targets
- Monitor profit margins and profitability trends
- Identify top-performing countries and product categories
- Create interactive reports to support data-driven decision-making

---

## 🛠️ Tools & Technologies

- Power BI Desktop
- Power Query

- Data Modelling
- Data Visualisation
- Microsoft Excel

---

## 📈 Dashboard Features

### KPI Overview
The dashboard provides key business metrics including:

- Total Sales
- Sales Targets
- Variance Analysis
- Variance Margin %
- Total Orders
- Total Costs
- Total Profit
- Profit Margin %

### Interactive Filters
Users can dynamically filter data by:

- Financial Year
- Country
- Region

### Sales Performance Analysis

The dashboard compares:

- Monthly Sales vs Targets
- Sales Trends by Financial Year
- Sales Performance Across Regions
- Sales Variance Analysis

### Profitability Analysis

Users can evaluate:

- Profit Margins over Time
- Overall Profitability
- Cost vs Revenue Performance
- Financial Performance Trends

### Product Analysis

The dashboard includes:

- Sales by Product Category
- Quantity Sold by Category
- Country-Level Sales Comparisons
- Product Performance Insights

---

## 📊 Key Insights

Some of the insights that can be identified from the dashboard include:

- Variations between actual sales and planned targets
- Regional differences in sales performance
- Product categories driving the highest revenue
- Trends in profit margins across reporting periods
- Opportunities to improve profitability in underperforming regions
